# Animal Sounds Webpage

A beautiful, interactive webpage that displays various animals and plays their actual sounds when clicked.

## Setup Instructions

### Option 1: Using Local Audio Files (Recommended)

1. Create an `audio` folder in the project root (already created)
2. Download animal sound files (MP3 format) and name them as follows:
   - `dog.mp3`
   - `cat.mp3`
   - `cow.mp3`
   - `pig.mp3`
   - `rooster.mp3`
   - `sheep.mp3`
   - `horse.mp3`
   - `duck.mp3`
   - `lion.mp3`
   - `elephant.mp3`
   - `monkey.mp3`
   - `owl.mp3`
   - `wolf.mp3`
   - `frog.mp3`
   - `bee.mp3`
   - `snake.mp3`
   - `bear.mp3`
   - `tiger.mp3`
   - `chicken.mp3`
   - `goat.mp3`

3. Place all audio files in the `audio` folder
4. Open `index.html` in your browser

### Option 2: Using Free Animal Sounds Sources

You can get free animal sounds from:
- [Freesound.org](https://freesound.org) - Search for animal sounds
- [Zapsplat](https://www.zapsplat.com) - Free sound effects library
- [Mixkit](https://mixkit.co/free-sound-effects/) - Free sound effects
- [Pixabay](https://pixabay.com/sound-effects/) - Free sound effects

## Features

- 🎨 Beautiful, modern UI with gradient background
- 🎵 Real animal sound playback using HTML5 Audio API
- 📱 Responsive design for all devices
- ✨ Smooth animations and hover effects
- 🎯 Visual feedback when sounds are playing

## Browser Compatibility

Works on all modern browsers that support HTML5 Audio API:
- Chrome/Edge
- Firefox
- Safari
- Opera

## Notes

- Audio files should be in MP3 format for best compatibility
- If an audio file is missing, you'll see an alert message
- Only one sound plays at a time (clicking another animal stops the current one)
